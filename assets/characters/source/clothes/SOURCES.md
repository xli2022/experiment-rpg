# Authored MakeHuman clothing sources

Retrieved October 3, 2026 from the [official MakeHuman system asset pack](https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip). Only these three original clothing directories are retained:

| Directory | Character base | Original directory |
| --- | --- | --- |
| `female_casualsuit01` | `flight` | [Female casual suit](https://download.tuxfamily.org/makehuman/assets/1.2/base/clothes/female_casualsuit01/) |
| `female_elegantsuit01` | `tailored` | [Female elegant suit](https://download.tuxfamily.org/makehuman/assets/1.2/base/clothes/female_elegantsuit01/) |
| `male_worksuit01` | `utility` | [Male work suit](https://download.tuxfamily.org/makehuman/assets/1.2/base/clothes/male_worksuit01/) |

Each directory contains the original OBJ mesh, MHCLO fitting data, MHMAT material description, diffuse/normal/AO textures, and thumbnail. These files are unmodified members of the current official pack. The source OBJ, MHCLO and MHMAT headers explicitly identify the assets as CC0. The [official catalog](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html) lists all three assets as CC0; the [MakeHuman asset license](https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md#c-the-license-for-the-bundled-assets) covers bundled meshes, textures and MHCLO assets. The CC0 terms are retained in [LICENSE.ASSETS.md](../LICENSE.ASSETS.md).

[DOWNLOADS.json](DOWNLOADS.json) records the exact archive URL, archive size and SHA-256, and each retained member's path, byte count and SHA-256. Earlier Tuxfamily copies were compared before replacement: mesh/fitting data and all diffuse/normal/AO image bytes match, apart from updated license comments and catalog tags. No MakeHuman program logic is included.
